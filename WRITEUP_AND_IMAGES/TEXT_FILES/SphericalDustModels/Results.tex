The results of the spherical dust models are reported in Table \ref{tab: dust_model_fits_spherical}. For each fitting case, at each porosity value, three values are reported: the best-fit scale factor from Equation \ref{eq: sf}, the $\chi^2$ value as a test of goodness-of-fit (Equation \ref{eq: chi_squared_dust_model}) and the best-fit grain size (the \amax that corresponds to the best SF). The best-fit for each fitting case is has bolded text. 


Additionally, the results of the fits are shown in Figure \ref{fig: Spherical_BEST} for the best fit overall, which is the scenario with no \bfiveNS. The equivalent plots for the other fits can be found in Appendix \ref{chap: Appendix_DustModels}. In this figure, the \POLFobs value for each wavelength is plotted as a colour-matching marker, the values of these are listed in Table \ref{tab: polf_comparison}, in the POLF$_{\text{max \SI}}$ column. 


These results revel that for all four cases, the best-fit (lowest chi-squared) offers when the porosity of the grains is set to have $f = 0.5$. The case of $f = 1.0$ is by far the worst fit for each fitting case, with a $\chi^2$ value significantly higher than at higher porosity (lower $f$), indicating that the dust grains are unlikely to be completely solid, and are likely slightly porous.
