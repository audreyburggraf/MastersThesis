\subsection{Finding Scale Factor and associated values}
% \label{sec: measured_POLF}
% ----------------------------------------------
To calculate the scale factor (\sftNS) we loop over all \amax values in the chosen grid \add{this grid}, we take the \Pwmodel values from the dust model, and \POLFobs (constant) and calculate the scale factor between the two:
\begin{equation}
\sfeq = \frac{\PwmodelEQ}{\POLFobsEQ},
    \label{eq: sf}
\end{equation}
\noindent for each \amax value and for each band that is included in the fit. This means for each \amax there are $n$ \sft values, where $n$ is the number of bands included in the fit. At each \amax value, we take the standard deviation between the $n$ values using \texttt{numpy.std}. The best \sft (\sfbestNS) is the lowest standard deviation value. 

From this, we also know the \amax value where this \sfbest value is, giving us the best fit \amax value (\amaxbestNS)

\subsubsection{Calculating chi-squared}
% \label{sec: measured_POLF}
% ----------------------------------------------
When calculating the chi-squared value, we consider \emph{all} bands, not just the ones that were used in the fit. However, when we measure the chi-squared value we \emph{never} include the typical Band 5 data. The data for Band 5 that is included in the chi-squared calculation is the robust = -1 data.

When we calculate the chi-squared value we use the equation:
\begin{equation}
\chi^2 = \sum_{all bands} (\POLFeq_{,obs} - \POLFeq_{,model})^2,
    \label{eq: chi_squared_dust_model}
\end{equation}
\noindent where $\POLFeq_{obs}$ is the observed \POLF value (the marker value) and $\POLFeq_{model}$ is the \Pw value multiplied by the scale factor. This value is taken at the \amaxbest value
