\subsubsection{\draft{Size Parameter, Wavelength and Grain Size }}
% ----------------------------------------------
A size parameter ($x$) is defined by:
\begin{equation}
    x = \frac{2\pi a}{\lambda},
\end{equation}
\noindent where $a$ is the physical radius of the particle, and $\lambda$ is its wavelength \citep{Zhang2023}. 
% ----------------------------------------------

% ----------------------------------------------
\subsubsection{\draft{Mie Theory }}
% ----------------------------------------------
The way the light interacts with the dust grain depends on the size parameter:
\begin{enumerate}
    \item $x << 1$: small particle, Rayleigh regime.
    \item $x \sim 1$: Mie regime. 
    \item $x >> 1$: geometric regime. 
\end{enumerate}

To calculate the dust models using Mie theory, we used the DSHARP Mie-Opacity Library (\texttt{DSHARP}) \citep{dsharp_code}. 
% ----------------------------------------------








\subsubsection{\ReadyToSend{Porosity and Density}}
Porosity ($\mathcal{P}$) refers to the fraction of a dust grain's volume that is empty space. A dust grain with a low porosity is compact (like a rock), and a grain with a high porosity has much more empty space (like a sponge).

Rather than specifying the porosity value, an alternate value called the filling factor ($f$) is used, which is defined as:
\begin{equation}
    f = 1 - \mathcal{P},
    \label{eq: filling factor}
\end{equation}
\noindent where $f=1$ corresponds to a compact grain ($\mathcal{P} = 0$), and an $f$ value less than 1 corresponds to a more porous grain \citep{Zhang2023}. Four different filling factors were considered ($f = 1, 0.75, 0.5, 0.25$) to sample a wide range of dust grain porosities. 

Each porosity ($\mathcal{P} = 1 - f$) was fed into the \texttt{do.get\_dsharp\_mix} function, which calculates the optical constants and the density of the dust mixture. These density values are shown in Table \ref{tab:dsharp_density}. As expected, the density decreases as the filling factor decreases (as the porosity increases).

\subsubsection{\draft{Computing Optical Properties}}


For each filling factor, \question{at a constant test $a$ value OR each $a$ in the distribution}, \texttt{DSHARP} computes a variety of parameters. These parameters include the mass absorption and scattering coefficients, \kabs and \kscaNS, respectively. These parameters \question{indicate how much a material absorbs versus scatters light?}. 

The effective scattering opacity (adjusted for forward scattering \citep{Zhang2023}) is calculated by:
\begin{equation}
    \kscaeffEQ = (1-g)\kscaEQ,
\end{equation}
\noindent where $g$ is the forward-scattering parameter \citep{Zhang2023} (the expectation value of $\cos\Theta$ \citep{dsharp_code}). 


An additional term we can calculate is the albedo, the reflectivity of a material \question{cite something?}. The (effective) albedo is defined by the fraction of (effective) scattered light to the total radiation:
\begin{equation}
    \omega = \frac{\kscaEQ}{\kabsEQ + \kscaEQ}, \quad 
    \weffEQ = \frac{\kscaeffEQ}{\kabsEQ + \kscaeffEQ}.
    \label{eq: omega}
\end{equation}
\noindent \citep{Zhang2023}.
