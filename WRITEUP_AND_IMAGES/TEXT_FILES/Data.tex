\subsection{Debiasing}


Observed polarized intensity is given by \POLIub, and it has a corresponding debiased intensity given by \POLI, with an error of \POLIerr. 

\section{Clean}

\begin{itemize}
    \item\ \quoted{We used the delivered calibrated uv-data and performed imaging with CASA version X  \cite{Stephens_2017}}.
    \item\ \quoted{We used the CASA  \texttt{tclean} task using  ... \cite{Stephens_2017}}.
    \item\ \quoted{After a quick clean, we performed a series of phase-only self-calibration iteration, and images were cleaned after each self-calibration iteration with progressively shorter solution intervals   \cite{Stephens_2017}}.
    \item\ \quoted{We first performed several rounds of self calibration to the \StokesI image only, and then did a final round of self calibration on all four Stokes parameters \cite{Stephens_2017}}.
    \item\ \quoted{Images were primary beam corrected.   \cite{Stephens_2017}}.
\end{itemize}




\section{ALMA Errors}
\begin{itemize}
    \item\ \quoted{The ALMA instrumental error on $P$ is expected to be about 1\%. In cases where the measured $P$ rms was less than this value, we used 0.1\% as our error.  \cite{Stephens_2017}}.
\end{itemize}
