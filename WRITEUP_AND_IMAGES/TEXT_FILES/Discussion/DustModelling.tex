\subsection{Implications for Dust Evolution}

The best-fit maximum dust grain sizes were found to be 245 \micron for spherical grains and \ibest \micron for irregular grains. ISM grains are typically on the order of $\sim$0.1 \micron \cite{Mathis}. Grains in the dense core of the molecular cloud are thought to be $\sim$1 \micronNS. The models indicate that the dust grains are approximately 2-3 orders of magnitude larger than those expected in ISM and core dust grains. What this is indicating is that the dust grains are larger than what would be expected if some planet formation process was not occurring. Essentially, this supports the main science question that dust self-scattering is occurring in IRS 63. Not only does it tell us this is happening in IRS 63, but since IRS 63 is a Class I disk, this is providing evidence on when planet formation occurs. This result is consistent with the prediction in \cite{Dom2020} that planet formation may begin during the Class I phase.
