The observed polarization fraction (\POLFobsNS) and the \Pwmodel values from dust model cannot be directly compared \add{why}. A scale factor (SF) is introduced to enable direct comparison between models and observations. 


The scale factor is calculated at each \amax in the sample, given by:
\begin{equation}
\sfeq_i(\amaxEQ) = \frac{\POLFobsiEQ(\amaxEQ)}{\PwmodeliEQ(\amaxEQ)},
    \label{eq: sf}
\end{equation}
\noindent where $i$ denotes each wavelength that is included in the fit. This provides the scale factor for each fitted wavelength at every value of \amaxNS. If the dust model correctly reproduces the observations, each fitted wavelength should find a similar scale factor. For every value of \amaxNS, the standard deviation of the scale factor values is taken using \texttt{numpy.std} to determine the spread between the scale factors at each wavelength:
\begin{equation}
    \text{SF}_{\text{STDEV}} = \text{STDEV}(\text{SF}_i(\amaxEQ).
    \label{eq: sf_std}
\end{equation}
% \begin{equation}
% \sfeq_{\text{STDEV}}(\amaxEQ) = \text{STDEV}\left(\frac{\POLFobsiEQ(\amaxEQ)}{\PwmodeliEQ(\amaxEQ)} \right).
%     \label{eq: sf_median}
% \end{equation}

The best-fit grain size (\amaxbestNS) is defined as the value of \amax where the standard deviation of the scale factors was the lowest. The corresponding scale factor is called the best-fit scale factor (\sfbestNS). The values of \Pwmodel are scaled by the best scale factor, allowing the model and observations to be directly compared.

A chi-squared value was calculated at each fitting combination and porosity to determine the agreement between the model and observations, given by: 
\begin{equation}
\chi_\mathcal{P}^2 = \sum_{all\text{ }wavelengths} (\POLFobsEQ- [\PwmodelEQ (\amaxbestEQ) \times \sfbestEQ])^2.
    \label{eq: chi_squared_dust_model}
\end{equation}
\noindent \add{divide by errors.} The calculation is summed over \emph{all wavelengths} as each wavelength was included in the $\chi_\mathcal{P}^2$ calculation, despite if it was included in the fit for the scale factor value or not. The fitting combination and porosity that produced the lowest chi-squared value was chosen to be the best-fit model.
