\subsubsection{Dust Size Distribution}
% ----------------------------------------------

The dust grains were assumed to have a size distribution of $n(a)\propto a^{3.5}$, chosen to match \cite{Kataoka_2015} and \cite{Zhang2023}. The minimum grain size is 0.1 \micronNS, and the maximum grain size is varied in logarithmic space up to a value of 5000 \micron, with 2000 values total. 

These values ranging up to 5000 \micron are denoted by \amaxNS.
