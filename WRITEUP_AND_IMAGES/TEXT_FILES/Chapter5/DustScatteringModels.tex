\subsection{\draft{Measuring Observed \POLF}}
\label{sec: measured_POLF}
% ----------------------------------------------
To compare the dust scattering models for spherical and irregular grains to observations, a single polarization fraction was needed at each wavelength. This value needed to be found in the region where the polarization morphology is aligned with the minor axis, or where dust self scattering dominates. 

Three different methods were tested:
\begin{enumerate}
    \item The polarization fraction at the pixel with maximum \SI.
    \item The polarization fraction at the pixel with maximum polarized intensity.
    \item The mean polarization fraction within the uniform area from the Gaussian model (= 1 $\pm$ 0.001). 
\end{enumerate}

\subsection{\draft{Determining the Best-Fit Scale Factor}}
% \label{sec: measured_POLF}
% ----------------------------------------------
At this point, each wavelength has an observed polarization fraction (\POLFobsNS), and the dust model provides \Pwmodel as a function of \amaxNS. The \Pwmodel curves and \POLFobs values cannot be directly compared. \add{A sentence on why the model and observations cannot be directly compared.} A scale factor (SF) is introduced to enable direct comparison between models and observations. 


The scale factor is calculated at each \amax value on this x-axis grid, given by:
\begin{equation}
\sfeq_i(\amaxEQ) = \frac{\POLFobsiEQ(\amaxEQ)}{\PwmodeliEQ(\amaxEQ)},
    \label{eq: sf}
\end{equation}
\noindent where $i$ denotes the wavelength that is included in the fit. This provides the scale factor for each fitted wavelength at every value of \amaxNS. If the dust model correctly reproduces the observations, each fitted wavelength should find a similar scale factor. Therefore, for every value of \amax, the standard deviation of the scale factor values is taken using \texttt{numpy.std}:
\begin{equation}
    \text{SF}_{\text{STDEV}} = \text{STDEV}(\text{SF}_i(\amaxEQ).
    \label{eq: sf_std}
\end{equation}
% \begin{equation}
% \sfeq_{\text{STDEV}}(\amaxEQ) = \text{STDEV}\left(\frac{\POLFobsiEQ(\amaxEQ)}{\PwmodeliEQ(\amaxEQ)} \right).
%     \label{eq: sf_median}
% \end{equation}

The best-fit grain size (\amaxbestNS) is defined as the value of \amax where the standard deviation of the scale factors was the lowest. The corresponding scale factor is called the best-fit scale factor (\sfbestNS). This scale factor is what the values of \Pwmodel are scaled by, allowing the model and observations to be directly compared.

To determine which fitting combination agrees best with the model, a chi-squared value ($\chi_\mathcal{P}^2$) is calculated for each fitting combination and porosity. The chi-squared value is calculated by summing the difference between the observed polarization fraction value and the \Pwmodel at the best-fit \amax value multiplied by the best-fit scale factor. It is summed over all bands, where ``all wavelengths'' refers to bfourNS, \bfive with \texttt{robust = -1}, \bsix and \bsevenNS. The standard Briggs weighted \bfive data is also excluded from all chi-squared calculations. The fitting combination and porosity that produced the lowest chi-squared value are chosen to be the best-fit model.
\begin{equation}
\chi_\mathcal{P}^2 = \sum_{all\text{ }bands} (\POLFobsEQ- [\PwmodelEQ (\amaxbestEQ) \times \sfbestEQ])^2.
    \label{eq: chi_squared_dust_model}
\end{equation}
