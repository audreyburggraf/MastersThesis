


\subsection{\SCC{Polarization Vector Sampling}}
\SCC{The Nyquist-Shannon sampling theorem} was used to determine the pixel spacing between polarization vectors. This ensures the vector spacing is not under- or over-sampled with respect to the relative size of the beam at each wavelength. This theorem ensures that the distance \SCC{between each vector is no larger than half of the size of the beam}. 

The size of the beam in pixels is:
\begin{equation}
    \text{Beam Size =} \sqrt{BMIN \cdot BMAJ},
    \label{eq: beam_size}
\end{equation}
\noindent where $BMIN$ and $BMAJ$ are the minor and major axes of the beam, listed in Table \ref{tab: source_info} in units of arcseconds. These values were converted to pixels using the image pixel scale of $0.018''\,\mathrm{pixel}^{-1}$ before using Equation \ref{eq: beam_size}. The beam size was divided in half, rounded to the nearest integer using \texttt{round}, and gave us the step size between vectors.

\subsection{Reliability Criteria}
\label{sec: methods_vector_criteria}
In addition to the sampling spacing explained above, a polarization vector was only plotted if it satisfied the following criteria:
\begin{enumerate}
    \item $\frac{\POLIeq}{\POLIerrEQ} >$ 4 (\bfour, \bfive, \bsevenNS) or $\frac{\POLIeq}{\POLIerrEQ} >$ 3 (\bsixNS) \notes{testing 2.4 for robust -1}
    \item $\PAerrEQ < 10^\circ$.
\end{enumerate}
\noindent These two criteria were adapted from the selection criteria from \citep{sadavoy_dust_2019}, without the additional condition of $I/\sigma_I>3$. This could be excluded for our analysis as IRS 63 is bright and well-resolved, meaning it has a high S/N ratio in the area around the disk, meaning this condition is already met. The threshold of $\frac{\POLIeq}{\POLIerrEQ} >3$ was used for \bsix because of its lower sensitivity. Using a threshold of 4 excluded almost 10 additional  polarization vectors.
